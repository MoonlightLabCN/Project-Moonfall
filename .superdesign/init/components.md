# UWP XAML Components

This repository is a Windows 10 UWP application using plain XAML and C# 7.3. Shared controls live under `src/MoonWeChat/Controls` and use dependency properties for avatar data and events for tab navigation.

## AvatarView
Source: `src/MoonWeChat/Controls/AvatarView.xaml` and `.xaml.cs`
Displays a square avatar with a generated initial and optional remote image fallback.

## BottomTabBar
Source: `src/MoonWeChat/Controls/BottomTabBar.xaml` and `.xaml.cs`
Four touch-sized navigation buttons for narrow layouts.
