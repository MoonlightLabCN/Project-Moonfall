# Theme Summary

The product is a third-party WeChat thin client. Win10 theme is light with WeChat green accent; WP Classic is dark with cyan-green accent. All colors, semantic text sizes, spacing, and chrome metrics are defined in `src/MoonWeChat/Styles/Themes/*.xaml` and consumed with `ThemeResource`.
