# MoonWeChat UWP Design System

Operational mobile-first chat client. The shell supports a 480px Windows 10 Mobile viewport and a desktop master-detail workspace. Use flat Windows 10 controls, 48px chrome, 48px minimum touch targets, compact list rows, and semantic text resources. The default Win10 theme uses a calm light surface and WeChat green; WP Classic uses black surfaces and cyan-green. Never introduce gradients, acrylic, WinUI 2 controls, hard-coded colors, or hard-coded font sizes.
